# 계산·실습 안내

이곳은 이론을 읽은 뒤 확인하는 실습편입니다. 처음이라면 [전체 흐름](theory_first.md)과 [학습 목차](../basic_track.md)를 먼저 읽습니다.

준비됐다면 [S0. 작은 필터 계산](S0.md)부터 시작합니다. 필수 순서는 **S0 → S1 → S2 → S3 → S4 → S6**입니다. 실제 모델 연결은 [선택 S5](S5.md)에서 다룹니다.

## 한 실습을 읽는 순서

1. **무엇을 알아낼지** 한 문장으로 읽습니다. 아직 낯선 개념은 앞의 이론 링크에서 확인합니다.
2. 작은 예제의 계산을 따라가고 **실행 전 예상**을 적습니다.
3. 명령을 한 단계씩 실행하고 **결과 표**와 비교합니다.
4. 다르면 **처음 달라진 항목**을 찾아 확인합니다. 맞으면 값 하나만 바꿔 다시 예상합니다.
5. 결과와 이유를 설명하고 다음 단계로 갑니다.

## 실행 환경은 한 가지를 고릅니다

**설치 없이 시작하려면:** [실습 노트북](https://colab.research.google.com/github/tsi03048/resnet20-accel/blob/main/notebooks/E1_E2_resnet20_reference.ipynb)을 엽니다. Colab은 브라우저에서 Python을 실행하는 환경이고, 셀은 설명이나 코드를 담은 한 칸입니다. 맨 위 준비 셀을 실행한 뒤 S0 칸으로 갑니다. 지금은 뒤의 S1~S3과 선택 전체 평가를 실행하지 않습니다.

**내 PC에서 하려면:** Python을 준비하고 [저장소](https://github.com/tsi03048/resnet20-accel)의 Code → Download ZIP으로 받은 파일을 압축 해제합니다. README.md와 exercises 폴더가 보이는 위치에서 터미널을 엽니다. 터미널은 글로 명령을 입력하는 창이며, Windows에서는 PowerShell을 사용할 수 있습니다. S0은 추가 패키지 없이 실행할 수 있습니다.

## 명령과 코드를 어디에 넣나요?

- `bash`라고 표시된 실행 명령은 터미널에 입력합니다. S0~S3의 `python ...` 명령은 Windows PowerShell에서도 실행할 수 있습니다. S4·S5의 회로 실행은 해당 문서의 Ubuntu/WSL 환경을 씁니다.
- `python`이라고 표시된 짧은 계산 예제는 노트북의 새 코드 셀에 넣습니다. 터미널 명령과 같은 칸에 섞지 않습니다.
- 로컬 명령은 README.md와 model·exercises 폴더가 함께 보이는 프로젝트 폴더에서 실행합니다. 노트북은 맨 위 준비 셀에서 실행 폴더를 보여 줍니다.
- JSON은 이름과 값이 짝지어진 결과 파일입니다. `lessons → quant → correct_code`라고 적혀 있으면 그 묶음들을 차례로 펼쳐 값을 읽습니다.

## 실행 자체가 안 되면

| 메시지·상태 | 먼저 할 일 |
| --- | --- |
| python을 찾지 못함 | Python을 설치했는지, 실행할 환경을 켰는지 확인합니다. 위의 Colab 준비 방법으로 S0부터 시작할 수 있습니다. |
| No module named exercises / model / quant | 실행 폴더에 해당 폴더가 있는지 확인합니다. 이름이 같은 빈 폴더를 만들지는 않습니다. |
| No module named numpy / torch / PIL | 같은 Python 환경에서 필요한 패키지를 설치합니다. S1은 requirements.txt, S3의 정수 재현은 NumPy를 사용합니다. |
| 파일을 찾지 못함 | 오류에 적힌 경로를 봅니다. 저장소 일부만 받은 것은 아닌지와 실행 위치를 확인합니다. |
| 노트북의 NameError | 앞 셀에서 만들 값이 없습니다. 준비 셀부터 위에서 아래로 다시 실행합니다. |
| 회로 도구를 찾지 못함 | S4·S5의 Ubuntu/WSL 준비를 확인합니다. 기존 자동 시험을 읽었다면 ‘기준 결과 열람’으로 기록합니다. |

## 통과와 기록

프로그램의 PASS는 그 프로그램이 검사한 조건을 만족했다는 뜻입니다. 학습에서는 **결과를 맞추고, 왜 그런지 설명하는 것**까지 확인합니다. 회로 시뮬레이션은 컴퓨터에서 회로 동작을 계산해 확인하는 것입니다. 소프트웨어 PASS, 회로 시뮬레이션 PASS, 실제 보드 PASS를 따로 적습니다.

실패했으면 오류 문구·처음 다른 항목·기대값·실제값을 남깁니다. 실행하지 않았다면 NOT_RUN입니다. 실행 때마다 결과 파일이 갱신될 수 있으니 값을 바꾸기 전에 원래 결과를 기록합니다.
