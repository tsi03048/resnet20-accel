# 처음 읽는 전체 흐름

이 프로젝트에서는 **사진을 보고 답을 고르는 계산을 배우고, 그 계산을 전자회로로 옮깁니다.**

## 사진 한 장이 답이 되기까지

**사진을 숫자로 읽기 → 작은 무늬 찾기 → 무늬를 조합하기 → 후보별 점수 내기 → 가장 높은 후보 고르기**

예를 들어 고양이·자동차 사진을 구분한다고 해 봅시다. 컴퓨터는 사진의 색을 숫자로 읽고, 그 숫자로 여러 계산을 합니다. 마지막에 고양이 점수가 자동차 점수보다 높으면 고양이를 답으로 고릅니다.

## 먼저 배우고, 배운 방법으로 답합니다

처음에는 잘못 답할 수 있습니다. 사진과 정답을 여러 번 보며 계산에 쓰는 숫자를 고치는 과정이 **학습**입니다. 학습이 끝난 숫자를 사용해 새 사진의 답을 내는 과정은 **추론**입니다. 이 계산 방법 전체를 **모델**이라고 부릅니다.

우리가 만들 회로는 주로 추론 계산을 맡습니다. 이미 학습된 모델을 가져와 컴퓨터 프로그램의 계산과 회로의 계산을 비교합니다.

## 앞으로 확인할 두 가지

1. 모델은 처음 보는 사진도 잘 맞히는가?
2. 회로는 모델과 같은 계산 결과를 내는가?

둘은 별도로 확인합니다. 사진의 정답을 맞혀도 중간 계산이 틀릴 수 있고, 계산을 정확히 옮겨도 모델 자체가 사진을 틀릴 수 있습니다.

## 여기서부터 차례로 읽습니다

**[A0. 모델·학습·추론](../fundamentals/A0.md)**으로 이어집니다. 각 장의 ‘다음 개념’을 따라가면 기본 이론을 읽은 뒤 실습에 도착합니다.

전체 순서를 찾아볼 때는 [학습 목차](../basic_track.md)를 엽니다. 문서 번호는 자료를 찾는 이름이므로 숫자순으로 읽지 않습니다. 예를 들어 정수 표현 A6은 전체 모델 B5를 이해한 다음 읽습니다.

각 장은 먼저 쉬운 설명과 작은 계산을 다룹니다. 펼치기 안의 상세 수식과 이전 기록은 필요한 때 읽습니다.
