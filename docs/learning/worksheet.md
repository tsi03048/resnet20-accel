- 이 결과로 설명할 수 있는 것 한 문장:

- 상태: PASS(검사 통과) / FAIL(실행했으나 검사 실패) / NOT_RUN(미실행) / BLOCKED(도구·자료 문제로 중단)

예: S0에서 X[0][0]을 1 늘리면 첫 창에만 들어가므로 출력은 [11,9,8,6]으로 예상했다. 실제값도 같았다. 다른 창에 안 들어가는 위치임을 그림에서 확인했다.

PASS만 적고 끝내지 말고 결과와 이유를 함께 남깁니다. FPGA 제출에는 [상세 제출 양식](../submission_template.md)의 보드·timing 기록을 추가합니다.
