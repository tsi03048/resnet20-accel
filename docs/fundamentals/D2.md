# ⚙️ D2. MAC을 반복하고 나누어 계산하기 — Partial Sum·Enable·재사용·병렬 실행

## MAC은 곱해서 중간 합에 더하는 계산입니다

**곱하기와 더하기를 반복해서 출력 하나를 만듭니다.** 지금까지 더한 값이 Psum입니다.

예를 들어 2×3 다음 4×1을 처리하면 Psum은 0→6→10입니다. 같은 곱셈기를 두 번 써도 됩니다. 곱셈기를 늘리면 여러 항을 동시에 처리할 수도 있습니다.

클록은 회로가 값을 저장하고 다음 동작으로 넘어가는 박자입니다. 데이터가 준비되지 않았다면 박자가 와도 계산을 기다려야 합니다.

**반복 횟수, 계산기 개수, 실제 걸리는 클록 수는 서로 다릅니다.** 먼저 순차 계산을 이해한 뒤 병렬화를 봅니다.

그림의 Partial Sum은 Psum과 같은 중간 합입니다. P는 한 출력에 들어갈 곱셈을 동시에 몇 개 하는지, Q는 출력 채널을 동시에 몇 개 만드는지 나타냅니다. 여러 계산을 동시에 하는 것이 병렬화입니다. 계산을 여러 단계로 나눠 서로 다른 입력을 차례로 겹쳐 처리하는 방식은 파이프라인이라고 합니다.
