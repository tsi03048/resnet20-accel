# 처음 읽는 순서에 맞춘 학습 그림

본문 설명과 작은 계산을 읽은 뒤 그림에서 같은 흐름을 따라갑니다. 학습 순서는 A0 → A1 → A2 → A3 → A4 → A5 → B1 → B2 → B3 → A7 → B4 → B5 → A6 → D1 → D2 → D3 → D5입니다. S6 그림은 보드 실행 절차를 읽은 뒤 봅니다.

| 그림 | 확인할 연결 |
| --- | --- |
| A0·A1 | 학습과 추론의 차이, 색 값과 사진 크기 |
| A2·A3 | 곱하고 더하기·ReLU, 앞 출력이 다음 입력이 되는 과정 |
| A4·A5 | 정답 확률과 벌점, 연습·점검·최종 시험의 역할 |
| B1·B2·B3 | 입력과 필터의 곱·합, 채널 합치기, 전체 평균에서 점수까지 |
| A7·B4·B5 | 평균 빼기, 원래 값 더하기, 모델 전체의 크기 변화 |
| A6·D1 | 정수와 눈금, 넓은 중간 합과 반올림 |
| D2·D3·D5 | 계산기 재사용, 필터 보관, 준비와 실제 전달 구분 |
| S6 | 초기화·시작·완료·결과 확인 |

각 PNG와 같은 이름의 SVG는 같은 도형·숫자에서 생성합니다. 원본은 [그림 생성 파일](../build_reading_diagrams.py)입니다. Python과 Pillow가 필요하며 Windows 기본 글꼴은 맑은 고딕입니다. 다른 운영체제에서는 `FONT_REG`·`FONT_BOLD`에 한글 글꼴 경로를 지정합니다.

```bash
python docs/figures/build_reading_diagrams.py
```

본문의 숫자를 그린 교육용 도식입니다. 모델 성능이나 보드 실행의 측정 결과가 아닙니다. B1은 사람이 정한 필터, B3는 두 후보로 줄인 예제, A7은 BN 전체 중 평균 빼기만 보여 줍니다. D2의 계산 횟수를 실제 클록 수로 읽지 않습니다. A4의 확률 비교와 Weight 수정은 별개 예제입니다.

기존 상세 이미지는 원본 그대로 보존하고 문서의 펼치기에 두었습니다. 실제 RTL 파형은 새로 그리지 않았으며, S4에서 신호 설명 뒤 기존 실행 기록을 보여 줍니다. 실제 Stem 계수 그림은 S5에서 각 숫자를 설명한 다음 읽습니다.
